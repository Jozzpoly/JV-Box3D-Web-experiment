## Scope

E2a2ae is a **bounded causal ablation** inside the contact-recycling shortcut. It is not product-physics acceptance.

Fixed apparatus:

- static-ground `SetTransform` diagnostic seam from E2a2y;
- spin `5 rad/s`;
- crossing rate `20 urad/s`;
- flat-P75 two-point carrier;
- friction `0`;
- coupled E2a2q normal solve;
- global warm starting ON.

On recycle-eligible shortcut steps, the intervention suppresses only the relative-motion separation reprojection term:

`separation = baseSeparation + dot(dp, normal)`

becomes

`separation = baseSeparation`.

Eligibility, cached anchors, `baseSeparation`, `persisted=true`, carried `normalImpulse`, shortcut continuation, contact identity and recycler cadence remain unchanged.

Controls:

1. normal recycling (`0.05 m`),
2. recycling with separation reprojection frozen (`0.05 m`),
3. recycling disabled (`0 m`).

Both `2 -> 1` and `1 -> 2` topology crossings are tested.

## Pre-experiment source-audit correction

The natural-boundary recommendation after E2a2ad proposed “fresh geometry + explicitly restore matched normalImpulse”. Source audit of pinned `b3UpdateContact` showed this would largely duplicate E2a2ac: fresh contact update already feature-matches new manifold points to old feature IDs, carries `normalImpulse` for matches, and marks those points persisted.

Therefore E2a2ae deliberately did **not** build that redundant intervention. The next unresolved semantic inside the shortcut was narrowed to recycled anchor/separation handling, and separation reprojection was chosen as the smallest one-variable causal split.

## Executed result

Workflow, donor recovery, composition, native/WASM build, Box3D.js tests and E2a2ae runtime all completed successfully.

### Validity gates

For all six runs:

- `contactDropoutsMotion = 0`;
- `contactIdChangesMotion = 0`;
- exactly one topology transition;
- exactly one old feature persists at transition.

For both directions, the freeze-separation arm preserved the normal recycler cadence and transition timing:

- `recycledStepsMotion = 90 / 180` for both normal and freeze-separation;
- `2 -> 1` transition step `310` in both;
- `1 -> 2` transition step `350` in both.

The intervention executed on `395` recycled manifold points in `2 -> 1` and `305` in `1 -> 2`.

### Transition velocity delta

| case | 2 -> 1 dVy | 1 -> 2 dVy |
|---|---:|---:|
| normal recycle | `+0.198434 mm/s` | `+0.248166 mm/s` |
| **freeze recycled separation reprojection** | **`-0.048092 mm/s`** | **`+0.000931 mm/s`** |
| recycle off | `-0.048312 mm/s` | `+0.000855 mm/s` |

The freeze-separation arm therefore collapses the amplified transient almost completely onto the recycle-off baseline while preserving recycler execution, cadence, old anchors, persisted state and carried normal impulse.

Absolute difference between freeze and recycle-off transition dVy:

- `2 -> 1`: about `0.000220 mm/s`;
- `1 -> 2`: about `0.000076 mm/s`.

This is orders of magnitude smaller than the normal-recycle amplification relative to recycle-off.

## Causal status

### TRUSTED EXECUTED / BOUNDED CAUSAL EVIDENCE

Within this exact static-ground-transform apparatus:

1. recycler eligibility/cadence alone is not sufficient for the amplified transition transient (E2a2ac);
2. carried normal impulse is not necessary and is not dominant (E2a2ad);
3. **the recycled relative-motion separation reprojection term is necessary for essentially all of the observed amplification** in E2a2ae;
4. retaining old anchors, persisted state, carried normalImpulse and shortcut cadence while suppressing only that term produces transition behavior nearly identical to fresh/recycle-off behavior.

This strongly localizes the measured effect to separation reprojection semantics rather than generic cache reuse.

## Critical interpretation boundary

Do **not** conclude from E2a2ae that Box3D contact recycling is generally wrong or that the reprojection formula is a product bug.

The current crossing is generated by repeatedly calling `b3Body_SetTransform` on a **static ground body** before stepping. E2a2y established that this is a clean contact-lifecycle diagnostic seam, but explicitly did not establish it as production-equivalent road motion.

That distinction is now first-order. The same reprojection term may behave differently when relative motion is generated on the dynamic wheel side while the road remains truly static. Continuing to dissect cached fields only inside the transformed-static-ground seam risks explaining an apparatus-specific interaction instead of representative wheel/road behavior.
